# Cybersecurity
 
This final project, titled "openguissl: A Window for openss1", is a Java application developed with JavaFX to provide a graphical interface for the openss1 command-line tool. It enables users to perform cryptographic operations such as file encryption, RSA key generation, secure password creation, and digital signatures.
