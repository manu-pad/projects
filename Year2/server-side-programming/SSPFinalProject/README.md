## Drone Assembly Management Project

* Develop a web application to manage the drone assembly process. The application should allow users to register, authenticate, and create, view, update, and delete information related to drone assembly. The API endpoints must be implemented following RESTful best practices. The endpoints should be documented using OpenAPI.

## Features:

* User authentication.
* Registration of new users.
* Management of parts required for drone assembly (e.g., motors, propellers, batteries, etc.).
* Management of drone assemblies, including the association of parts and assembly dates.
* Viewing drone assemblies by user.
* Updating and deleting drone assemblies.
* Viewing statistics on the assembly process (e.g., total number of assemblies, most used parts, etc.).

## Technologies Used:

* Node.js
* Express.js
* Mongoose
* MongoDB
* JWT Authentication

## Technical Requirements:

* Implementation of API endpoints using Express.js.
* Use of MongoDB/Mongoose to store data.
* Implementation of JWT authentication to secure API endpoints.
* Clear and concise API endpoint documentation.
